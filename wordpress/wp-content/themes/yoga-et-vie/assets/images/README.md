# Images du thème

Illustrations vectorielles **originales**, créées pour ce projet (aucune image tierce), utilisées en
attendant de vraies photos de l'association :

| Fichier | Usage |
| --- | --- |
| `hero-montagnes.svg` | Image en arche du bandeau d'accueil (à remplacer par une photo portrait) |
| `illustration-cercle.svg`, `illustration-souffle.svg`, `illustration-sentier.svg` | Illustrations de sections (à remplacer par des photos) |
| `portrait-a-venir.svg` | Emplacement de portrait des enseignant·e·s |
| `ridge-line.svg`, `mountain-edge.svg` | Ornements (séparateur « Montagnes », crête du pied de page) |

**Logo** : voir `branding/README.md`. Le fichier source officiel vit dans `branding/` (non retouché) ;
les dérivés web utilisés par le site de démonstration sont générés dans `tools/demo-content/images/`
et importés dans la médiathèque par `tools/seed-demo-content.php`, qui définit le logo du site et
l'icône du site (favicon).
