# Images du thème

Illustrations vectorielles **originales**, créées pour ce projet (aucune image tierce) :

| Fichier | Usage |
| --- | --- |
| `logo-mark.svg` | Pictogramme du logo **provisoire** |
| `hero-montagnes.svg` | Image en arche du bandeau d'accueil (à remplacer par une photo portrait) |
| `illustration-cercle.svg`, `illustration-souffle.svg`, `illustration-sentier.svg` | Illustrations de sections (à remplacer par des photos) |
| `portrait-a-venir.svg` | Emplacement de portrait des enseignant·e·s |
| `ridge-line.svg`, `mountain-edge.svg` | Ornements (séparateur « Montagnes », crête du pied de page) |

**Logo définitif** : le téléverser dans la médiathèque et le choisir dans *Apparence › Éditeur › En-tête › Logo du site*
(ou *Réglages › Général › Icône du site* pour l'icône d'onglet). Le fichier source du logo peut être rangé ici
sous `logo/` s'il doit être versionné.
