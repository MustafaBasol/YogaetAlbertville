# Images de démonstration

Importées par `tools/seed-demo-content.php` et supprimées par `tools/remove-demo-content.php`.

- `yoga-et-vie-logo.png`, `yoga-et-vie-icon.png` : dérivés web du **logo officiel** de l'association
  (source intacte : `wordpress/wp-content/themes/yoga-et-vie/assets/images/branding/yoga-et-vie-logo-original.png`).
  Générés par un simple redimensionnement/mise sur fond carré transparent — aucun recadrage du contenu,
  aucune recoloration. Voir `assets/images/branding/README.md` pour le détail.
- `evenement-*.webp`, `actualite-site.webp` : illustrations générées pour ce projet à partir des SVG
  originaux du thème (`wordpress/wp-content/themes/yoga-et-vie/assets/images/`), converties en WebP.
  Aucune image tierce, aucune contrainte de droits.

Les images d'événements sont à remplacer par les photos réelles de l'association (avec accord des
personnes photographiées).
